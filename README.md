# DESCRIPTION
The objective of this task is to create an interactive dashboard for visualizing sales data using Power BI. The dashboard presents important business insights through charts, graphs, and visual indicators. Various visualizations such as sales by country, product performance, order status distribution, and monthly sales trends were created to provide meaningful insights and support data-driven decision-making.

# OBSERVATIONS
1. The dashboard successfully visualized sales data using interactive charts and graphs.

2. Country-wise analysis showed differences in sales contribution across regions.

3. Product line visualization identified high-performing product categories.

4. Order status charts helped understand completed, cancelled, and disputed orders.

5. Monthly sales trends revealed fluctuations in sales performance over time.

6. Interactive visuals improved the understanding of business insights and sales patterns.

7. The dashboard provided a user-friendly representation of the dataset for decision-making purposes.
